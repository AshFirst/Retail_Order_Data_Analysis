# Orders Data Analysis

This repository contains SQL queries and a Python script for analyzing sales data from an e-commerce dataset. The analysis includes revenue insights, sales trends, and profitability calculations.

📌 Features

SQL Queries:

Top 10 highest revenue-generating products.

Top 5 highest-selling products in each region.

Month-over-month sales growth comparison for 2022 and 2023.

Identifying the month with the highest sales for each category.

Finding the sub-category with the highest profit growth from 2022 to 2023.

Python Data Processing:

Data cleaning and renaming columns.

Calculating discount, sale price, and profit.

Converting order dates to datetime format.

Removing unnecessary columns for efficiency.

📂 Files

orders.csv: Sample dataset containing e-commerce order details.

analysis.sql: SQL queries to extract insights from the dataset.

data_processing.py: Python script for preprocessing and transforming data.

🔧 Setup & Usage

Prerequisites

Ensure you have the following installed:

Python (>=3.7)

Pandas library (pip install pandas)

A database (MySQL, PostgreSQL, SQL Server) for running SQL queries

Running the Python Script

python data_processing.py

Running SQL Queries

Execute the queries in your SQL environment (e.g., MySQL Workbench, PostgreSQL, or SQL Server Management Studio).
